# Portfolio expansion

Four separately owned concept chats build on local commit `f443014`, alongside Morrow and RIFT. `portfolio-expansion.json` records their chat IDs, isolated checkouts, module paths, and preview ports.

Each concept must deliver a clear fictional brief, design rationale, consistent original product imagery, a case study, and a usable storefront prototype. Typography, layout, palette, and interaction direction should demonstrate a different design decision. AI imagery and self-initiated work must be disclosed. Claims of client work, sales, verified production performance, or live Shopify integration require actual evidence.

SABLE explores fashion and leather accessories; DAYBREAK explores packaged coffee; ARC explores lighting and material selection; SIDE B explores records and expressive print artwork. All are self-initiated concepts. SABLE and ARC include separately labeled Shopify source proposals, with no automatic theme upload.

Review every completed module before copying it into the parent repository. Inspect its integration manifest, assets, font provenance, link destinations, mobile screenshots, keyboard states, reduced motion, and shopping checks. Preserve the existing Shopify product pages and bag. Rebuild the combined portfolio and check the six-project navigation and all storefront interactions before presenting a preview.

Publishing requires a reviewed preview. Netlify deployment and Shopify theme upload are separate operations. No chat may publish, upload, push, or modify the parent checkout. GitHub push remains blocked by the current account's repository permissions.
