# Self-hosted SIDE B fonts

Retrieved from the Google Fonts source repository on 3 October 2026. Files are unmodified font binaries; CSS uses namespaced family aliases without modifying font metadata.

## Ultra Regular

Designer: Astigmatic / Brian J. Bonislawsky. Font copyright: Copyright (c) 2010 by Brian J. Bonislawsky DBA Astigmatic (AOETI). Available under Apache 2.0.

- Binary: https://raw.githubusercontent.com/google/fonts/main/apache/ultra/Ultra-Regular.ttf
- Metadata: https://raw.githubusercontent.com/google/fonts/main/apache/ultra/METADATA.pb
- Licence: https://raw.githubusercontent.com/google/fonts/main/apache/ultra/LICENSE.txt
- Local files: `Ultra-Regular.ttf`, `Ultra-LICENSE.txt`
- CSS alias: `SideB Ultra`; fallback: Rockwell, Georgia, serif.

Ultra was selected for its wide, heavy slab silhouette, suited to cover and poster lettering. It differs from Morrow's serif restraint and RIFT's compact sans lettering.

## Chivo variable, upright

Designer: Omnibus-Type. Copyright 2019 The Chivo Project Authors (https://github.com/Omnibus-Type/Chivo). Licensed under SIL Open Font License 1.1.

- Binary: https://raw.githubusercontent.com/google/fonts/main/ofl/chivo/Chivo%5Bwght%5D.ttf
- Metadata: https://github.com/google/fonts/blob/main/ofl/chivo/METADATA.pb
- Licence: https://github.com/google/fonts/blob/main/ofl/chivo/OFL.txt
- Local files: `Chivo-Variable.ttf`, `Chivo-OFL.txt`
- CSS alias: `SideB Chivo`; fallback: Arial, Helvetica, sans-serif.

Chivo carries the useful information beneath expressive display type. Upright variable weights cover body, labels and controls; no synthetic italic is required.

The Shopify source contains identical copies renamed `side-b-ultra.ttf` and `side-b-chivo.ttf` to fit a flat theme-assets directory. Include these licence and attribution files when distributing that source. The original graphic SVGs embed Ultra for deterministic browser rendering; generated PNG artwork and physical photos are final visual assets.
